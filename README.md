# RFQ-to-Quote Costing Application

A full-stack application for automotive component manufacturers to manage
customer RFQs, automate part costing, maintain rate masters, and generate
quotations.

## Technology Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma ORM

### Testing
- Vitest
- Supertest

## Project Structure

- client/: Frontend application
- server/: Backend application
- docs/: Technical documentation

## Project Status

Under development.

## Important Note

All sample manufacturing data and costing assumptions used in the
prototype are illustrative unless explicitly identified otherwise.

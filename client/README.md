# ForgeFlow web client

The React/Vite client is part of ForgeFlow. See the repository [README](../README.md) for setup, role provisioning, and the end-to-end RFQ-to-quotation demonstration. Client commands are `npm run dev`, `npm run lint`, and `npm run build` from this directory. The client calls the API at `http://localhost:5000/api` by default; set `VITE_API_BASE_URL` at build time to override it.
